ADR-0001: 결정 문서는 레포 안의 HTML로 관리한다

accepted 작성일 YYYY-MM-DD 작성자 이름

결정

팀의 결정·역할·스펙 문서는 코드와 같은 레포의 docs/ 아래에 HTML 파일로 둔다. 같은 내용을 다른 도구(Notion, Confluence, Google Docs 등)에 따로 두지 않는다.

이유

  • 코드 옆에 산다 — 코드를 고칠 때 문서가 함께 보여서 한쪽만 낡지 않는다.
  • 변경 이력이 남는다 — 누가 언제 어느 줄을 왜 바꿨는지 git에 남는다. 초안에 대한 논의는 PR 리뷰에서 한다.
  • 열기 쉽다 — 브라우저에서 바로 열린다. 비개발자도 클릭 한 번으로 보고, 표·이미지·색을 쓸 수 있다.
  • 사람과 AI가 같은 문서를 읽는다 — AI에게 일을 맡길 때 이 문서부터 읽게 하면 팀 규칙에 맞는 결과가 나온다.

버린 것

  • Notion / Confluence / Google Docs — 코드와 떨어져 있어서 결국 한쪽이 낡는다. 두 곳에 같은 규칙이 있으면 사람마다 다른 쪽을 믿게 된다.
  • Markdown — 레포 안에 둘 수 있다는 장점은 같다. 하지만 비개발자가 브라우저에서 바로 열어 보기 어렵고 표·색 표현에 한계가 있다. 팀이 원하면 새 ADR로 바꿀 수 있다.
