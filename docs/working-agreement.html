일하는 방식

최종 수정 YYYY-MM-DD

사람과 AI가 같이 따르는 규칙이다. README와 AGENTS.md는 이 문서를 가리키기만 한다. 규칙을 바꿀 때는 여기만 고친다.

진실은 한 군데에만

  • 같은 사실을 두 곳에 쓰지 않는다. 이미 다른 곳에 있으면 복사하지 말고 링크를 건다.
  • 문서 사이에 모순이 보이면 둘 다 고쳐 맞추지 말고 하나를 지운다.
  • 레포가 여러 개인 프로젝트라면 문서가 사는 레포를 하나로 정한다. 다른 레포에는 링크만 둔다.

진행 상황, 할 일문서에 쓰지 않는다. 이슈 트래커를 쓴다

초안과 논의

  • 확정되지 않은 내용도 먼저 올린다. ADR·스펙 초안은 status: draft로 PR을 연다.
  • 의견은 PR 리뷰 댓글로 주고받는다. 합의되면 accepted로 바꾸고 머지한다.
  • 확정된 ADR은 고치지 않는다. 번복할 때는 새 ADR을 만들고 기존 문서를 superseded로 표시해 새 문서를 링크한다.

리뷰 규칙

  • 취향 의견은 내지 않는다. 기준은 문서에 있다.
  • 문서와 다르면 코드를 고치거나, 문서를 먼저 고친다.
  • 리뷰에서 나온 결론은 문서에 반영한다.
